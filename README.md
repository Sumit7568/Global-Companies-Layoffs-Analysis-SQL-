🌍 Global Companies Layoffs Analysis (SQL)
📌 Project Overview

This project analyzes global layoff trends across companies and industries using structured query language (SQL) to extract meaningful business insights from real-world data.

🎯 Objective

To understand layoff patterns over time, identify affected industries and regions, and analyze company-level workforce reductions.

🧠 Key Analysis

Layoffs by company, industry, and country

Trends across different time periods

Identification of companies with highest layoffs

Impact of layoffs across sectors

🛠 Tools & Technologies

SQL

Relational Databases

Data Cleaning & Aggregation

Analytical Queries

📈 Outcome

The analysis provides data-driven insights into workforce trends, helping understand economic and industry-level impacts of layoffs.
